# CyberGuard - Advanced Password Strength Checker 🛡️

A high-tech, interactive web application that evaluates password strength in real-time. Designed with a premium cyberpunk aesthetic, it calculates password entropy, estimates brute-force cracking time, and provides an automatic secure password generator.

## 🚀 Live Demo
[Click here to view the live project on Vercel](https://passwordstrengthcheckermodel.vercel.app/)

## ✨ Key Features
* **Real-time Entropy Calculation:** Dynamically scores passwords as you type based on character variety and length.
* **Brute-Force Time Estimator:** Mathematically calculates how long it would take modern hardware to crack the password.
* **Interactive Checklist:** Visual validation for security requirements (length, uppercase, lowercase, numbers, symbols).
* **Secure Password Generator:** One-click generation of 16-character cryptographically strong passwords.
* **Premium UI/UX:** Neon glassmorphism design with smooth CSS micro-animations.

## 🛠️ Tech Stack
* **HTML5:** Semantic structure
* **CSS3 (Vanilla):** Custom variables, flexbox/grid, backdrop filters, and keyframe animations
* **JavaScript (ES6):** Core logic, DOM manipulation, event listeners, and math algorithms
* **Vite:** Next-generation frontend tooling for instant server start and lightning-fast HMR

## 💻 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/MohsinAliRandhawa/password-strength-checker.git
   ```
2. Navigate into the directory:
   ```bash
   cd password-strength-checker
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the Vite development server:
   ```bash
   npm run dev
   ```
